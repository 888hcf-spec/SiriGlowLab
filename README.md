SiriGlowLab

Research project exploring Siri-style rainbow edge glow effects on iOS.

Device and Environment

* Device: iPhone 13
* iOS version: 27.0.1
* Current status: Research and feasibility testing

Project Goals

* Study the visual design of Siri rainbow edge lighting.
* Build a standalone visual prototype for testing the animation.
* Investigate whether native Siri integration is technically possible on the target iOS version.
* Document installation, signing, and compatibility limitations.

Important Limitations

A normal iOS app cannot directly modify the system Siri interface. Native integration may require system-level capabilities, compatible jailbreak or tweak support, or other methods that must be verified.

This project does not claim native Siri integration or iOS 27.0.1 compatibility until tested.

Status

Early research stage. No working native Siri modification is currently confirmed.
